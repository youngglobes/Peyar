Full Peyar runs on v0.2.0 (2026-11-21), each made by a fresh Claude agent working only from `SKILL.md`. The briefs say nothing about language, so these show the default **mix** of global, alphanumeric and Indian-language names.

| File | Brief | Finalists |
|---|---|---|
| [cold-brew-bengaluru.md](cold-brew-bengaluru.md) | Ready-to-drink cold brew, Bengaluru → pan-India, SG/Dubai | Jetbrew, Coldfuse, Vega, **560 Cold**, Kovo |
| [ev-charging-hyderabad.md](ev-charging-hyderabad.md) | EV 2W/3W fast-charging network + app, Hyderabad → 10 cities | Kilovo, **Amp23**, **Volt78**, Zaptu, Plugwala |
| [pet-food-mumbai.md](pet-food-mumbai.md) | Fresh-cooked pet food subscription, Mumbai → metros | Tailpot, **Tail91**, Ladle, Larder, Katori |

Bold = alphanumeric (560 = Bengaluru PIN prefix, 78 = Hyderabad's longitude, 91 = India's dial code).

Notes:
- Availability was true **on 2026-11-21 only**. Names may be registered since.
- Example names are illustrations, not recommendations. Do your own trade mark search.
