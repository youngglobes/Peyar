# Indian language and pronunciation screen

"Every name is a sound." Before shortlisting, run each candidate through this screen.

## 1. Meaning screen (checklist C1–C3)

For each candidate, check the **full word, each half, and any embedded sub-string of 3+ letters** in:

| Language | Main states / markets | Notes |
|---|---|---|
| Hindi | North, Central, pan-India | Check common slang and abuse sub-strings |
| Urdu | North, Hyderabad, Lucknow | Overlaps Hindi; Persian roots |
| Bengali | WB, Tripura, Bangladesh | |
| Marathi | Maharashtra | |
| Gujarati | Gujarat, diaspora | |
| Punjabi | Punjab, Delhi, diaspora (Canada/UK) | |
| Tamil | TN, Puducherry, Sri Lanka, Singapore, Malaysia | |
| Telugu | AP, Telangana | |
| Kannada | Karnataka | |
| Malayalam | Kerala, GCC diaspora | |
| Odia | Odisha | |
| English (Indian + global) | Everywhere | Check Indian English slang and internet slang |

**Be honest about limits.** An LLM's slang knowledge in Indian languages is incomplete, and street slang changes fast. Always:
1. Give your best reading with a confidence level (high/medium/low).
2. Flag every language you **cannot** vouch for.
3. Tell the user to run the final 3 names past **at least one native speaker per target-market language**. A WhatsApp message to friends is enough.

### Starter red-flag list (NOT exhaustive)

## 2. Accent traps (checklist B3)

Common sound mergers across Indian English accents. A name that depends on these distinctions will be said, spelt and searched in two ways.

| Trap | Example of the problem |
|---|---|
| **v / w** | "Wave" and "Vave" sound the same in many regions |
| **z / j** | "Zest" becomes "Jest" in parts of North and East India |
| **f / ph / p** | "Fable" becomes "Pable" in some regions; ph/f spelling confusion |
| **sh / s** | "Shine" becomes "Sine" in parts of Bengal and the East |
| **th / t / d** | English "th" doesn't exist in most Indian languages |
| **Short / long vowels** | "Mala" vs "Maala" carry different meanings |
| **Initial consonant clusters** (st-, sk-, sp-) | Often get a vowel added in front ("istation", "iskool") in parts of North India |
| **Ending consonant** | Tamil and Telugu speakers often add a "-u": "Brand" becomes "Brandu" |
| **Silent letters** | "Knight", "Psych": people spell what they hear |
| **Double letters** | "Swiggy" vs "Swigy": search and spelling split |

## 3. Script check (checklist F1)

Write the name in Devanagari and in the main target-market scripts (Tamil, Telugu, Kannada, Bengali and others). Check that:
- It doesn't form a different word when transliterated.
- The conjuncts look clean on packaging and signage.
- Vernacular users can **search** it: Indians type brand names in English letters and in their own script on Google and YouTube.

## 4. Export check (checklist F4)

If the brand plans to sell abroad, also screen Spanish, Portuguese, Arabic (GCC), Malay/Indonesian and French. The classic warning is Mitsubishi's "Pajero", sold as "Montero" in Spanish markets because of a slang meaning.

## 5. Regional vs English (from the video)

"We are going very heavy on English names." Indian founders default to English. Regional languages are an under-used source, and the inspiration can come from the geography you serve. The trade-off: a regional name that delights Coimbatore may stumble in Delhi or Dubai. **Name for the geography you will actually sell in over the next 5 years.**
